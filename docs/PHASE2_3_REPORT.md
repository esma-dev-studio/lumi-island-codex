# Lumi Island Phase 2.3 最終報告

実施日: 2026-07-31
基準コミット: `1f6f96ca2b7c1556ba39c1bf92f451ee1858f407`

## 結論

Phase 2.3では、Phase 2.2を独立監査し、経済、実際に遊べる解放、初期進行、子ども向けメニュー、タッチ入力、ノラの親密度、完全E2E、初回JS容量を改修しました。新規セーブを直接書き換えない完全導線は、移動、採集、工作、家具配置、会話、森の修復、セーブ、再読込まで成功しています。

ゲーム本体のPhase 2.3改善は公開候補です。ただし、4体のキャラクターGLBは引き続き統合確認用の仮素材で、`production-character-glb`ゲートは **FAILED / OPEN** です。本番キャラクター品質まで完了したとは扱いません。

## 1. 独立監査で見つけた問題

`docs/PHASE2_3_AUDIT.md`に11件を記録しました。主なP0は、初期120Lで主要購入がすぐ終わる、解放が表示だけ、初期依頼中に非表示の日替わりが進む、初期家具と工作が矛盾する、メニューが過密、タッチ入力が二重になる可能性でした。P1は、親密度が数値だけ、採取開始時に成功演出、seed依存E2E、Validator状態の二値化、5.47MBの巨大チャンクです。

監査時のPlaywrightは15件中10成功・1失敗・4未実行であり、成功扱いしませんでした。修正後に全体を再実行しています。

## 2. 経済の修正前後

| 項目 | Phase 2.2 | Phase 2.3 |

| 初期家具 | 小えだのいす1個 | なし |

## 3. 解放後に増える実際の遊び

- 小島への橋: 修理前は通行できない小島へ移動でき、固有採取物「星しずく草」と短い発見が増えます。修理状態はversion 4セーブへ保存します。
- 港の釣り場: 図鑑50%で新しい釣り位置が現れ、既存場所と異なる2種の魚と難度を追加します。解放前は釣れません。
- 夜の庭: 図鑑75%後、夜だけ反応・発光・採取できる2種の植物が増えます。昼は採取できません。住民会話にも差分があります。
- 木もれ日の森: 12 / 18 / 24 Lの3段階で、見た目に加えて実、ハーブ、光るキノコの採取地点が順に増えます。
- ノラの作業場: 親密度3で作業場と短い思い出イベントが有効になります。

表示フラグだけでなく、Interactable、ResourceDefinition、魚テーブル、時間条件、セーブ復元へ接続しました。

## 4. 初期進行と日替わり

- 初期バッグの小えだのいすを0個にし、最初の椅子は自分で作る体験に統一しました。
- 初期依頼中は日替わり目標を生成・加算しません。
- 5件の初期依頼を終えた翌ゲーム日から、短い目標を1件だけ表示します。
- 日替わりは未解放エリアを要求せず、報酬は10 Lです。
- チュートリアル中は通常依頼を重ねず、メニューや島づくり画面を開いた時は案内カードを隠して見出しとの重なりを防ぎます。

## 6. タッチ入力

`TouchMovementController`へ押下状態を集約しました。pointerdownで開始、pointerup / pointercancel / pointerleave / lostpointercapture / blur / ポーズで解除します。pointerイベントにclickの追加入力を重ねないため、指を離した後の余計な一歩を防ぎます。PCでは方向パッドを隠し、coarse pointer / hoverなし環境だけに表示します。単体テストでは複数方向、全解除経路、二重押下を確認します。

## 7. ノラの親密度3段階

- 1: 通常会話と最初の依頼。
- 2: 木材を渡す固有進行、木工会話、固有レシピ。
- 3: ノラの作業場、短い思い出イベント、会話差分。

会話連打だけでは上がらず、会話、好きな木材、ノラの近くへ指定家具を置く条件を分けました。上昇時は変化内容を表示し、状態はセーブ・復元します。

## 8. 完全な新規ゲームE2E

このファイルには`localStorage.setItem`、`page.evaluate`によるセーブ注入、storageStateの差し替えはありません。ゲーム内操作だけで完走します。

## 11. Validatorとキャラクターゲート

Validator状態を`passed` / `failed` / `unavailable`の3値で記録できるようにしました。今回の`gltf-validator`は実行可能で、結果は`failed`です。実行不能をアセットエラーへ誤算入していません。

4体のGLBは`integration-placeholder`で、UV0なし、画像テクスチャなし、複数関節ウェイトなし、Khronos errorありのため、`productionGateStatus: failed`です。新しいプロシージャル仮GLBは生成していません。`artifacts/character-gate-phase2-3.json`を証跡とします。
