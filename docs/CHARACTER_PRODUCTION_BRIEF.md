# Lumi Island — プレイヤーキャラクター外部制作仕様

## 現状と目的

現在の `mira.glb` は、ゲームロジック・スケルトン・アニメーション接続を検証するための仮モデルです。GLB形式ではありますが、プロシージャル形状で、UV・画像テクスチャ・自然なスキンウェイトを備えた商品品質のモデルではありません。

この仕様書は、Lumi Island のプレイヤー「ミラ」を、既存の操作・アニメーションコードを壊さずに差し替えられる本番用GLBとして制作するための引継ぎ資料です。

## アート要件

- 対象: 小学2年生を中心とした子ども向け。親しみやすく、怖さや過度な写実感を避ける
- 方向性: 手作り感のある上質なスタイライズド3D。大きめの頭、読み取りやすい表情、丸いシルエット
- 衣装: 島の探索に合うジャケット、ショートブーツ、小さなバッグ
- 色: ティール、コーラル、生成りを中心に、背景から常に識別できる明度差を確保
- 顔: 正面・斜め・背面で破綻しない目、眉、口。無表情でも穏やかに見えること
- 参照画像: `public/assets/characters/phase2-character-turnaround.png`

## 技術仕様

- 形式: glTF 2.0 binary（`.glb`）
- スケール: 1 unit = 1 m、足元原点、Y-up、正面は +Z
- ポリゴン: 15,000〜35,000 triangles
- マテリアル: 3〜6個、PBR metallic-roughness
- UV: UV0必須。重なりは左右対称部など意図した箇所のみ
- テクスチャ: 2Kを基本に BaseColor、Normal、ORM。目・顔は十分な解像度を確保
- ボーン: 25〜35本程度。root / hips / spine / neck / head / arms / hands / legs / feet を含む
- ウェイト: 1頂点あたり最大4ボーン、正規化済み。肘・膝・肩・股関節・手首の曲げで潰れや尖りがないこと
- 不要データ: ライト、カメラ、非表示メッシュ、未使用マテリアル、外部参照を含めない
- 圧縮: 初回納品は無圧縮GLB。動作確認後にMeshoptまたはDracoを別版で提出

## 納品物

- `mira-production.glb`
- Blender原本（テクスチャをPack Resourcesしたもの）
- テクスチャ原本
- ターンアラウンド画像（正面・側面・背面）
- 肘90度、膝90度、しゃがみ、腕上げの変形確認画像
- 使用ツール、制作担当、ライセンス、第三者素材の一覧

## 合格条件

1. Khronos glTF Validatorで error 0
2. Babylon.js Sandboxとゲーム本体の両方で外部ファイル参照エラーがない
3. 正面・側面・背面・夜間で輪郭と顔が判読できる
4. 肘・膝・肩・股関節のウェイトが自然
5. 全必須クリップがコード上の状態遷移後に再生され、終了クリップが途中で上書きされない
6. デスクトップでプレイ中の描画負荷が現行版から著しく悪化しない
7. 子ども3名以上の観察で、キャラクターを「怖い」「人形が壊れている」と評価する重大反応がない

## 差し替え手順

1. 納品GLBを `public/assets/characters/mira-production.glb` に配置
2. `src/characters/CharacterConfig.ts` のモデルURLとクリップ名を更新
3. 型チェック、単体テスト、E2Eを実行
4. `phase2-1-player-front/side/back/joint-bend/night.png` を再撮影
5. 本書の合格条件を満たした後、仮モデルを削除
