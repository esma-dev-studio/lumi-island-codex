# Release checklist

## Progression and saves

- Verify 25, 50, 75, and 100 percent collection reachability.
- Test prior save versions and milestone reconstruction without duplicate rewards.
- Verify all purchase orders remain finite and no failed purchase charges currency.
- Verify real NPC talk advances talk objectives once.

## Child UX

- One visually dominant next objective.
- Easy mode is the new-player default.
- Destructive new-game action requires confirmation when a save exists.
- Main touch targets are at least 44 CSS pixels.
- Buttons use short action labels; difficult Japanese uses reading or simpler wording.

## 3D and lifecycle

- Production characters pass UV, texture, skin, hierarchy, animation, rights, and Khronos gates.
- Shared materials are not disposed by individual meshes or placement ghosts.
- Scene observers, listeners, timers, sounds, meshes, materials, and textures have explicit ownership.

## Evidence

- Unit, typecheck, lint, build, and browser console results are recorded.
- Normal journeys are separated from debug-assisted functional E2E.
- Measured performance is separated from bundle proxies and future targets.
- Browser screenshots include a machine-readable manifest.
- Scores follow the current rubric and known blockers cap the result.
